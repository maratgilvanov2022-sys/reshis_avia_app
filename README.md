# Решись Авиа — Система динамического ценообразования и прогнозирования спроса

Веб-приложение для сотрудников авиакомпании «Решись Авиа», предназначенное для расчёта пассажирского спроса, прогнозирования итоговых продаж билетов и визуализации сценариев загрузки рейса при изменении цены.

---

## Основной функционал

* **Регистрация и авторизация сотрудников:** Встроенная система управления доступом с хранением учётных записей в базе данных SQLite, криптографическим хешированием паролей (PBKDF2-HMAC-SHA256) и защитой API-запросов по токену сессии.
* **Интерактивный подбор параметров рейса:** Выбор аэропортов отправления и назначения из выпадающих списков, календарь даты вылета с ограничением по расписанию, а также автоматическая подстановка базовой цены и подсказка рекомендуемого ценового диапазона.
* **Расчёт прогноза продаж:** Мгновенное вычисление ожидаемого спроса и реальных продаж с учётом ценовой эластичности маршрута и максимальной вместимости самолёта (`seats`).
* **Визуализация квантильного распределения:** Столбчатая диаграмма спроса по всем 9 квантилям (от `0.1` до `0.9`) на нативном HTML5 Canvas с выделением медианного прогноза (`0.5`) и отметкой лимита кресел на борту.

---

## Технологический стек

* **Backend:** Python 3, FastAPI, Uvicorn, Pandas, Pydantic, SQLite.
* **Frontend:** HTML5, CSS3 (адаптивная тёмная тема в палитре индиго и графит), нативный JavaScript (ES6+), HTML5 Canvas API.
* **Хостинг и деплой:** GitHub + Render.com.

## Локальный запуск

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   git clone <URL_вашего_репозитория>
   cd reshis_avia_app
   ```

2. **Установите необходимые библиотеки:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите сервер:**
   ```bash
   python main.py
   ```

4. **Откройте приложение в браузере:**
   Перейдите по адресу `http://127.0.0.1:8000`, зарегистрируйте учётную запись сотрудника и выполните расчёт для нужного рейса.
